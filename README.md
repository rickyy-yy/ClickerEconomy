ClickerEconomy is a Minecraft plugin that lets players earn Vault currency by clicking an item inside a chest-style GUI. It's built for customization and performance — works out of the box with zero setup, but scales up with random rewards, jackpots, timed multipliers, leaderboards, and full database support for larger servers.
 
## Features
 
- GUI clicker with live-updating balance, click count, and lore
- Fixed or random rewards with an optional jackpot system
- Global multipliers (permanent or timed) that persist across restarts
- Personal multipliers via permissions, stacking with the global multiplier
- Paginated click leaderboard and player stats
- Anti-spam protection with configurable cooldowns
- Multiple storage backends (YAML, H2, MySQL, MariaDB, PostgreSQL)
- Full PlaceholderAPI integration
- Fully translatable with `&` color codes and `&#RRGGBB` hex support
- Custom skull textures, animated item names, and configurable sounds
- Smart config migration between plugin versions

## Server Compatibility
 
ClickerEconomy is compatible with Spigot and any forks. We recommend using [Paper](https://papermc.io/) to run your server. CraftBukkit servers will not be compatible with the plugin.
 
We support Minecraft versions **1.16** and newer running **Java 17**.
